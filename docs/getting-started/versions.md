# Compatibility

Laravel Helpers 4.0.0 supports the following combinations. GitHub Actions exercises each Laravel/PHP combination in the table.

| Laravel | PHP | Status |
| --- | --- | --- |
| 13.x | 8.3, 8.4, 8.5 | Recommended |
| 12.x | 8.2, 8.3, 8.4, 8.5 | Compatible |

Laravel 11 and earlier are not supported by 4.x. Laravel 11 has reached the end of its security support; upgrade the framework before installing this release. The Composer constraint `^13.0` includes Laravel 13 minor and patch releases, not future major releases. See the [Laravel support policy](https://laravel.com/docs/13.x/releases#support-policy) for the framework's PHP and security support dates.

The version Composer installs comes from the Git tag (`v4.0.0` for this release). See the [release notes](/getting-started/changelog) for changes from 3.x.
